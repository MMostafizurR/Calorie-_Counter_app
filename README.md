# 🥗 Python & Django Calorie Counter App

A full-stack web application designed to help users track their daily food intake, monitor nutritional data, and manage their daily calorie goals. Built using **Python and Django**, this project focuses on practical database management, user authentication, and interactive data tracking.

---

## ✨ Key Features

* **User Authentication & Profiles:** Secure registration and login system so each user maintains their own private food and calorie logs.
* **Daily Calorie Tracking:** Add, edit, and delete food items consumed throughout the day with automatic calorie and macronutrient calculation.
* **Dashboard & Summary:** Clear visual overview of total calories consumed versus daily recommended intake limits.
* **Food Database / Search:** Quick lookups for common food items and their respective calorie values.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django (MVT Architecture)
* **Database:** SQLite (Default Django DB)
* **Frontend:** HTML5, CSS3, Bootstrap (for clean, responsive forms and dashboards)
* **Authentication:** Django Built-in Auth & Session Management
